# RoadSideRescue API 🚗

A real-time roadside assistance platform connecting stranded drivers with nearby service agents.

## 🚀 Features
- Real-time request matching (SignalR)
- JWT-based authentication
- Dual database support (SQLite & PostgreSQL)
- Modular service architecture

## 📋 Prerequisites
- .NET 8 or later
- PostgreSQL (or SQLite for local dev)
- Next.js (frontend)
